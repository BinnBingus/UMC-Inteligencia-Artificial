# UMC - Inteligência Artificial

Este repositório contém a lista de exercícios e implementações práticas desenvolvidas durante a disciplina de **Inteligência Artificial** no curso de **Engenharia de Software** na **UMC**.

O objetivo deste projeto é consolidar os fundamentos da linguagem Python aplicados à lógica de programação, manipulação de dados e algoritmos base para IA.

---

## Conteúdo do Repositório

O repositório é composto por:
*   `Exercícios_Python_FernandoGabrielArakawaDe...ipynb`: Um notebook contendo **50 exercícios práticos** desenvolvidos e testados utilizando o Google Colab.
*   `README.md`: Documentação principal do repositório.

---

## Conteúdo dos Exercícios 

Os 50 exercícios cobrem a trilha fundamental de lógica em Python necessária para o desenvolvimento de modelos de IA, divididos entre:

1.  **Fundamentos da Linguagem:** Manipulação de variáveis, tipos de dados (Inteiros, Floats, Strings) e operadores matemáticos.
2.  **Estruturas de Controle:** Tomada de decisão com condicionais (`if/else`).
3.  **Estruturas de Repetição:** Laços de repetição (`for` e `while`) para automação de tarefas.

---

## Tecnologias Utilizadas

*   **Python 3** - Linguagem base do projeto.
*   **Google Colab** - Ambiente de desenvolvimento em nuvem utilizado para escrever e executar o código.
