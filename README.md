# UMC - Inteligência Artificial

Este repositório contém a lista de exercícios e implementações práticas desenvolvidas durante a disciplina de **Inteligência Artificial** no curso de [Nome do seu Curso, ex: Ciência da Computação / Engenharia de Software] na **UMC**.

O objetivo deste projeto é consolidar os fundamentos da linguagem Python aplicados à lógica de programação, manipulação de dados e algoritmos base para IA.

---

## 📌 Conteúdo do Repositório

O repositório é composto por:
*   `Exercícios_Python_FernandoGabrielArakawaDe...ipynb`: Um notebook contendo **50 exercícios práticos** desenvolvidos e testados utilizando o Google Colab.
*   `README.md`: Documentação principal do repositório.

---

## 📖 Conteúdo dos Exercícios (Tópicos Abordados)

Os 50 exercícios cobrem a trilha fundamental de lógica em Python necessária para o desenvolvimento de modelos de IA, divididos entre:

1.  **Fundamentos da Linguagem:** Manipulação de variáveis, tipos de dados (Inteiros, Floats, Strings) e operadores matemáticos.
2.  **Estruturas de Controle:** Tomada de decisão com condicionais (`if/else`) e tratamento de exceções com `try/except` para validação de dados.
3.  **Estruturas de Repetição:** Laços de repetição (`for` e `while`) para automação de tarefas.
4.  **Manipulação de Textos e Dados:** Métodos de strings (como remoção de espaços com `.replace()` e `.strip()`) e estruturas de dados como listas e dicionários.
5.  **Algoritmos e Lógica de IA:** 
    *   Cálculo de frequência de caracteres e contagem de dados.
    *   Algoritmos de ordenação estruturais (como o *Insertion Sort* ou Ordenação por Inserção).

## 🚀 Como Executar o Projeto

Como os exercícios foram criados utilizando o ambiente do Google Colab, você pode rodá-los diretamente no navegador:

1. Faça o download do arquivo `.ipynb` deste repositório.
2. Acesse o [Google Colab](https://google.com).
3. Clique em **File (Arquivo)** > **Upload notebook (Fazer upload de notebook)**.
4. Selecione o arquivo baixado e execute as células de código.
